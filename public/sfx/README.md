# 効果音（12枠）

ここに `<枠>.m4a` と `<枠>.ogg` を置き、`src/render/audio.ts` の `SFX_FILES` に枠の名前を足すと、その枠の効果音が置き換わります。
ファイルがない枠は、今までどおり合成音が鳴ります。

| 枠 | 使われる場面 |
|---|---|
| decide | 決定・カードをめくる |
| deny | できない操作 |
| clock | 時計が進む・相手の時計を進める |
| bell | 鐘（終焉の刻は低く再生） |
| resv | 予約・残響・予約の公開 |
| summon | ユニットを出す |
| spell | 術・回復・充填・カードを引く |
| attack | 攻撃・拠点へのダメージ（大きいダメージは低く強く） |
| destroy | ユニットが倒れる |
| win | 勝ち |
| lose | 負け |
| pack | パックを破る・開く・コイン・レア（レアほど高く） |

- 形式：.m4a（AAC）と .ogg（Opus）の両方。48kHz、短い音はモノラル。
- 音量：ピークは −1dBFS 以下。ほかの枠と聞こえ方の大きさをそろえる。
- 長さの目安：decide・deny・clock は0.2秒以内、戦闘の音は0.5秒以内、win・lose は3秒以内。
- 同じ枠を高さを変えて使い回すので、音の頭がはっきりしていて、余韻が短めの音が扱いやすいです。
