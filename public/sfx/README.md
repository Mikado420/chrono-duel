# 効果音

`<名前>.m4a` と `<名前>.ogg` を置き、`src/render/audio.ts` の `SFX_FILES` に名前を足すと、その効果音がファイルで鳴ります（ないものは合成音）。
入れるときは、頭と終わりの無音を切り、聞こえる大きさをそろえて（RMS −18dBFS・ピーク −1dBFS）、48kHz モノラルで書き出しています。

| 名前 | 鳴る場面 |
|---|---|
| select | 決定 |
| flip | カードをめくる・引く |
| deny | できない操作 |
| clock | 時計が進む・相手の時計を進める |
| bell | 鐘（終焉の刻は低く再生） |
| resv | 予約・残響・予約の公開（未作成） |
| battle_card | ユニットを出す |
| spell | 術・充填 |
| heal | 回復 |
| attack | ユニットへの攻撃 |
| base_destroy | 拠点へのダメージ（大きいダメージは低く強く） |
| destroy | ユニットが倒れる |
| win / lose | 勝ち・負け（未作成） |
| pack | パックを破る・開く・コイン・レア（レアほど高く） |
