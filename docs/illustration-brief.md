# カードイラスト指示書（全53枚）

別のAIにイラストを描いてもらうための指示書です。最初の「共通の指定」と参考画像2枚（描き方の参考のみ）を毎回いっしょに渡し、そのあとに描くカードの項目を1つ渡してください。

各カードの「人物」「構図」「背景」「雰囲気」は、場面の意図です。要素が多いときは、「共通の指定」の「描きこみの量」に従って、少ない要素にまとめてください。「共通の指定」は、その絵をどう描くか（画風・光・色）を決めます。

## 共通の指定（全カードに必ず添える）

- **画風（最重要）：** 添付の参考画像2枚のような、日本のスマートフォン向けカードゲームのカードイラスト調。**絵の描き方だけを参考にし、参考画像の人物・衣装・構図・小物をそのまま写してはならない。** キャラクターもデザインも、このゲーム用に新しく作る。
- **描きこみの量（これが最優先。AI画像生成で最も起こりやすい失敗）：** 絵は「描きこむ」のではなく「整理する」。カードは小さく表示されるので、細かい描きこみは見えず、ただの汚れや雑音になる。
  - **情報量の配分：** 描きこみは、主役の顔・目・手と、視線の先（武器や魔法の中心）の1〜2か所に集中させる。それ以外は、大きくて単純な面で塗る。画面の6〜7割は、細部のない落ち着いた面にする。
  - **衣装：** 服の模様・刺繍・金具・ベルト・鎖・ひび割れ・破れ・ほつれ・金線の装飾は、**全体で3種類まで**。それぞれ大きく、単純な形にする。布は大きな面と少ないしわで描き、全面に細かい模様を入れない。
  - **背景：** 場面が分かる程度の大きな形（塔、アーチ、空、雲）だけにして、細部は省略する。遠景は、輪郭が見えない淡い色の塊にする。石畳のひび、建物の窓の1つ1つ、街並みの屋根の連なり、雲のちぎれ方などを描き分けない。背景は人物より少しぼかし、彩度とコントラストを落とす。
  - **効果（光・魔法・粒子）：** 画面に入れる発光効果は、**主役の効果1つと、補助の効果1つまで**。小さな光の粒、水しぶき、光の輪、光の線を画面じゅうに散らさない。
  - **要素の数：** 1枚の絵に入れるもの（人物・道具・背景のモチーフ・効果）は、**主役を含めて最大4つ**。各カードの項目に挙げた要素が多い場合は、フレーバーとカード名にもっとも関係するものを優先し、残りは省く。
  - **確認方法：** 絵を幅304ピクセルに縮小して、何の場面かがひと目で分かること。主役のシルエットが背景と分離していること。分からないときは、細部を減らす。
  - **避けること：** 全面に細かい装飾が入った衣装、至るところに散らばる光の粒や水しぶき、ひび割れや汚れを全面に描いた石畳、建物がびっしり並んだ背景、画面全体が同じ密度で描かれていること、金属の細かい反射を何か所にも入れること。
- **全体の質感：** 丁寧に仕上げたデジタル塗り。アニメ調の顔に、整理された大きな面で服・金属・背景を塗る。
- **線画：** 主役の輪郭は、やや太めのはっきりした線にする。髪や服の線は、少ない線で流れをつくる。線は黒一色にせず、髪や肌の近くでは色つきの濃い線にして、塗りになじませる。
- **塗り：** 光と影を、なめらかなグラデーションと、はっきりした面の塗り分けの両方で描く。影は2〜3段階にまとめる。金属は、大きな反射を1か所、布は大きなしわを数本だけ入れる。
- **光：** 光源を1つはっきり決め、リムライト（輪郭の縁取りの光）と、逆光または反射光のどちらかで立体感を出す。魔法は周囲を照らす光源として描く。
- **目と顔：** 大きく澄んだ目に、色の変化のある虹彩と、はっきりしたハイライトを入れる。表情は場面に合わせてしっかり演技させる（笑う、見据える、叫ぶ、祈るなど）。
- **髪：** 3〜5本の大きな房にまとめ、流れが見えるシルエットにする。1本ずつの細い毛は描かない。毛先に光を入れる。
- **構図（ここに工夫を出す）：** 描きこみを減らした分、構図で見せる。カードごとに「カメラ・構図の型」を指定してあるので、必ずそれに従う。型の意味は次のとおり。
  - **対角線：** 主役と動きの向きを、画面の左下〜右上（または逆）の対角に通す。水平・垂直に並べない。
  - **額縁（フレーム内フレーム）：** 鐘の口、アーチ、文字盤の輪、窓、鳥籠などを前景に置いて、主役を囲む。
  - **極端なあおり／俯瞰：** 地面すれすれから見上げる、または真上から見下ろす。顔の高さのカメラにしない。
  - **前景の大きなぼかし：** 手前に大きな手・武器・物を置いてぼかし、ピントは奥の主役に合わせる。
  - **スケール対比：** 巨大なものと、小さな人物を並べて、大きさを見せる。
  - **シルエットと逆光：** 主役を暗い影の形にして、背後の光で輪郭を見せる。
  - **余白：** 主役を画面の三分割線の位置に小さく置き、反対側を広い空白にする。緊張や孤独を見せる。
  - **視線誘導：** 腕・武器・光の筋・道が、画面の1点に集まるようにする。
  - **円・同心円：** 時計の文字盤、鐘、波紋の輪を、画面の骨格にする（このゲームの主題）。
  - **左右対称：** 中央線で左右をそろえ、静けさと荘厳さを出す。
  - **分割・反復：** 画面を斜めや上下に割って2つの状態を見せる、または同じ形を並べてリズムをつくる。
  - **共通のルール：** 顔は正面だけにしない。横顔・後ろ姿・見下ろし・見上げなど、53枚で向きを散らす。8:5の横長を生かし、主役を三分割線のどちらかに置き、反対側に効果や余白を置く。型を使っても、1枚に入れる要素は主役を含め最大4つのまま。
- **ここまでの要約：** 主役ははっきり、背景は静かに、効果は少なく。

- **色：** 各カードの場面に合わせて色を決める。夜や嵐の場面は深い青・紺・紫と淡い発光、朝や昼の場面は明るい空色・白・金、など、場面の時間帯と気分で選ぶ。全体を通して次のルールで統一する。
  - 時の魔力は、淡いシアン〜白の発光で表す。
  - 真鍮・金色の金属を、差し色として使う。
  - 明暗の差をはっきりつけ、暗い場面でも主役の顔まわりは明るく保つ。1枚の色数は、主役の色・背景の色・発光色の3系統にしぼる。
  - ユニットは青緑寄り、術は紫紺寄りのトーンを、背景の空気感に少し混ぜる（カードの地の色になじませるため）。
- **世界観：** 時間を魔力として操る世界。時計塔・鐘楼・歯車・振り子・砂時計・針が、建物や武具、魔法の形として日常にとけこんでいる。中世〜近世ヨーロッパ風の石造りの街と、真鍮の機械仕掛けが混ざった世界。
- **入れてはいけないもの：** 文字、数字、ロゴ、枠線、カードの縁、透かし。時計の文字盤を描くときも数字は入れず、目盛りだけにする。
- **画面比率：** 横長 8:5（カード上の絵の枠は 304×190。生成は 1600×1000 程度を推奨）。四辺が少し切れても主役が欠けないよう、主役の顔は中央寄りに置き、外周に少し余白を残す。
- **セットごとの演出：**
  - 基本：はっきりした時計・歯車・砂時計のモチーフ
  - 第1弾「残響の刻」：音の波紋（同心円）、半透明に重なる残像、鐘の響き。「遅れて届く」「くり返す」が主題
- **レア度ごとの迫力（描きこみの量ではなく、構図の大きさと光の強さで表す）：**
  - C：主役だけ。背景はほぼ色の面。効果は1つ
  - R：主役と、場面を示す背景の大きな形を1つ。効果は1〜2つ
  - E：主役を大きく、あおりなど大胆な構図。効果は大きく1つ（小さな粒を増やさない）
  - L：もっとも壮大な構図と、もっとも強い光。ただし要素の数は他のレア度と同じ（主役を含め最大4つ）。細部を増やさず、スケールの大きさと光で見せる
