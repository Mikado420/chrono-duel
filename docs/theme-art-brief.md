# テーマイラスト指示書（8テーマ × 文字盤・スリーブ・プレイマット ＝ 24枚）

各「プロンプト」を、そのまま丸ごと画像生成AIに貼ってください（1枚ずつ単独で使えます）。
同じ部品の型紙（`docs/theme-templates/`）を一緒に添えると、構図が外れにくくなります。添えるときは次の一言をつけてください。

> 添付画像は構図の型紙です。色の塗り分けと文字は描かず、区画の配置（主役の位置・暗くする帯・何も置かない場所）だけに従ってください。

## ゲームへの組み込み方（描く人が知っておくこと）

- 絵は「背景」として敷きます。金属の縁・額縁、目盛り・数字・針、鐘の飾り、レーンの枠、「CHRONO DUEL」の文字は、ゲームがその上に描きます。**絵に枠・文字・数字・時計の目盛りを描かないでください。**
- 文字盤は、絵の幅いっぱいを盤の内側（金属の縁の内側の半円）に合わせて敷き、半円に切り抜きます。半円の外は捨てるので、何が写っていても構いません。縁は外側にゲームが描くので、絵の端まで盤として見えます。
- プレイマットは自分側に敷き、相手側には**上下逆さ**で敷きます。真上から見下ろした面（床・地面・机・水面）として描き、空・地平線・立っている人物は入れません。
- 8テーマとも、カードイラストと同じ画風（日本のスマホカードゲーム風のアニメ背景美術、描き込みは少なめ）で揃えます。
